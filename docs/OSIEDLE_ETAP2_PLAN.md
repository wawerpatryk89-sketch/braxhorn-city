# Osiedle — aktualny plan etapu 2

Wykonany układ: `dev/osiedle/review/plan-osiedla.png`.
Źródło współrzędnych: `dev/osiedle/layout.js`; generator planu: `dev/osiedle/tools/draw_plan.py`.

| Strefa | Zawartość |
|---|---|
| Północ | Park Wiśniowy, boisko, drążki i alejki |
| Północny środek | Willa Wawera Wiśniowa 4, dom kontaktowy, garaże i brama leśna |
| Środek | Sześć pozostałych domów przy Wiśniowej; Bydgoska i Poznańska |
| Zachód | Kasyno, dyskoteka i sala bokserska |
| Wschód | Komisariat, szpital i hala z oktagonem |
| Południe | Brama do centrum, połączenie planowane na później |

Łącznie 8 domów (willa i dom kontaktowy są wliczone), 6 obiektów publicznych/rozrywkowych/sportowych.
Przygotowane punkty misji i strefy walk nie uruchamiają jeszcze NPC, samochodów, walk ani wypłat.

Kasyno używa dostarczonego Gameready Casino scene, a nie historycznego skanu Romanian Casino.
Wybrane materiały, ograniczenia i stan testów opisuje `docs/HANDOFF_OSIEDLE.md`.
Nie korzystać ze starych propozycji modeli odrzuconych przez użytkownika jako z listy do pobrania.
