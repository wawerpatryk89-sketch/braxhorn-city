# Drzewo Verdant (gra)

Źródło: części drzewa z paczki „Verdant Trail” właściciela (dev/source-assets/verdant-trail), już obecne
w scenie osiedla jako EstateMesh_439 (pień, gałęzie) i EstateMesh_453 (liście, island_tree / jacaranda,
tekstury Poly Haven CC0). Wersja do gry: karty liści przerzedzone losowo (55% / 30% / 12% / 4%) i powiększone
wokół własnego środka (1.25 / 1.6 / 2.4 / 3.8), żeby korona została pełna przy 49k / 28k / 13k / 6k trójkątów
zamiast 175k (czwarty poziom na dalekie drzewa w parku). Skrypt: unity-tools/claude/drzewo/build_tree.py + extract.py.
