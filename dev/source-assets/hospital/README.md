# Szpital — oryginalna paczka użytkownika

`Hospital_assets.zip` — oryginał bez zmian. Autor: Madduck, itch.io, Free Modular 3D hospital environment.

Wyeksportowano łóżko, krzesło i wózek; przypisano dostarczone tekstury koloru, normalnych i chropowatości. Kopie gry mają tekstury do 1024 px. Skrypt: `dev/osiedle/tools/export_hospital.py`.

Budynek, rejestracja i cztery gabinety zostały zbudowane w `civic.js`; nie są gotowym zewnętrznym modelem szpitala.
