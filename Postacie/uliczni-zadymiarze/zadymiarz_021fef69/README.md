# Zadymiarz z głową psa

Globalna postać do późniejszego przypisania przez obsadę rejonu.

Spoczynek, chód, siadanie, siedzenie, wstawanie, rozmowa, machanie i wskazywanie. Bieg, skok i bójka uliczna. Pięć ataków obejmuje trzy uderzenia ręką, kopnięcie boczne i uderzenie kolanem. Dostępne są unik, blok i dwie reakcje na trafienie. Pozycja bojowa włącza się przy pierwszym własnym ataku lub otrzymanym trafieniu.

Własny model Mixamo, 65 kości, limit tekstur do 2048 px. Po rozpakowaniu paczki w repo wybierz w Unity **Braxhorn → Postacie → Zadymiarz z głową psa**. Powstaje prefab `Assets/Source/Prywatne/Postacie/zadymiarz_021fef69/Zadymiarz021fef69.prefab`.
