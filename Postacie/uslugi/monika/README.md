# Monika

[Aktualny podgląd ruchu w Unity, wszystkie 14 postaci](https://github.com/wawerpatryk89-sketch/braxhorn-city/releases/download/untagged-4487374c3ba5c1e097f9/Braxhorn_Postacie_T_role_14.pdf)

Globalna postać usługowa z najnowszego modelu właściciela. Dostępna do obsadzenia na siłowni i dyskotece. Konkretna usługa, zadanie i rejon zostaną przydzielone później.

| Zastosowanie | Ruchy |
| --- | --- |
| Codzienne (11) | Spoczynek, chód, bieg, skok, siadanie, odpoczynek na siedząco, wstawanie, rozmowa, machanie, wskazywanie, picie |
| Dyskoteka (2) | House, hip-hop |
| Siłownia (3) | Pajacyki, unoszenie ramion w przód, wymach odważnikiem |

Model zachowuje oryginalny szkielet Mixamo. Kontroler zaczyna w stanie Idle. Bazowe 13 klipów jest w archiwum Moniki. Trzy ćwiczenia pochodzą ze [wspólnej paczki siłowni](../../silownia/). Po rozpakowaniu paczki bazowej przygotuj ćwiczenia poleceniem `python3 unity-tools/claude/gym.py /sciezka/do/gym.zip monika` z katalogu głównego repozytorium. W Unity wybierz **Braxhorn → Postacie → Przygotuj Monikę**. Postać korzysta z osobnego prefabu i kontrolera. Sprawdzono 16 ruchów i zgodność siatki, UV, wag i szkieletu w Blenderze.
