# Aneta

[Aktualny podgląd ruchu w Unity, wszystkie 14 postaci](https://github.com/wawerpatryk89-sketch/braxhorn-city/releases/download/untagged-4487374c3ba5c1e097f9/Braxhorn_Postacie_T_role_14.pdf)

Usługi / Fitness. Anetę można też obsadzić w dyskotece. Każdy rejon może wskazać tę samą postać przez identyfikator `aneta`. Rejon i zadanie zostaną ustalone później.

Aneta stoi w zwykłym spoczynku i nie uczestniczy w bójkach. Ma 15 klipów na szkielecie Mixamo:

| Zastosowanie | Ruchy |
| --- | --- |
| Codzienne | Spoczynek, chód, bieg, skok, siadanie, odpoczynek na siedząco, wstawanie, rozmowa, machanie, wskazywanie, picie |
| Fitness | Rozgrzewka ramion, trucht treningowy |
| Dyskoteka | House, hip-hop |

Po rozpakowaniu paczki na gałęzi z kartą Anety wybierz w edytorze Unity **Braxhorn → Postacie → Przygotuj Anetę**. Polecenie tworzy jej prefab i kontroler. Sprawdzono ruchy i zgodność modelu ze źródłem w Blenderze. Test w scenie gry pozostaje do wykonania.
