# Liga

Zawodnicy ligi z indywidualnymi stylami walki.

Po potwierdzeniu zawodnika dobierz do jego stylu normalne poruszanie się, spoczynek, gesty, sześć ataków (trzy ręką i trzy nogą), uniki, blok, reakcje na trafienie oraz ruchy do treningu i sparingu w klatce. Zawodnik uruchamia pozycję bojową przy pierwszym własnym ataku lub po otrzymanym trafieniu.
