# Patryk

[Aktualny podgląd ruchu w Unity, wszystkie 14 postaci](https://github.com/wawerpatryk89-sketch/braxhorn-city/releases/download/untagged-4487374c3ba5c1e097f9/Braxhorn_Postacie_T_role_14.pdf)

Gracz Osiedla, dostępny jako postać globalna. Profil gry korzysta z 47 ruchów z zestawu T i 3 ćwiczeń siłowni. Obejmuje m.in. spoczynek, chód, bieg, rozmowę, gesty, siadanie, dwa tańce, pływanie, jazdę autem i walkę. Pod rzut do kręgli przypisany jest wskazany przez właściciela ruch bramkarza. Początkowy pakiet modelu z 13 listopada zawierał 31 klipów.
