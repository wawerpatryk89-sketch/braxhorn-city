# Chłopiec w okularach

Globalna postać do późniejszego przypisania przez obsadę rejonu.

Spoczynek, chód, siadanie, siedzenie, wstawanie, rozmowa, machanie i wskazywanie. Bieg, skok i kopnięcie piłki. Do obsady tłumu lub placu zabaw.

Własny model Mixamo, 65 kości, limit tekstur do 2048 px. Po rozpakowaniu paczki w repo wybierz w Unity **Braxhorn → Postacie → Chłopiec w okularach**. Powstaje prefab `Assets/Source/Prywatne/Postacie/dziecko_003f4e46/Chlopiec003f4e46.prefab`.
